# Tutorial: Autopilot Setup

Autopilot turns a list of topics into scheduled posts at fixed times of day. This tutorial sets up two posts a day for a week.

<img src="https://raw.githubusercontent.com/CodesbyFebin/Open-Post/main/assets/screenshots/autopilot.png" alt="Autopilot screen" width="100%">

## 1. Prerequisites

- At least one channel. Use a `sandbox` channel while you experiment.
- Set `TZ` in `.env` (e.g. `TZ=Asia/Kolkata`). Cadence times use the server's local time.
- Optional: an AI provider (see [Tutorial: LLM Providers](Tutorial-LLM-Providers)). Without one, the offline heuristic engine is used.

## 2. Add topics

In the **Topic queue** card, enter a topic and a pillar, then click **Add**. Tick **evergreen** for topics you're happy to revisit.

| Topic | Pillar | Evergreen |
| --- | --- | --- |
| What we learned moving our scheduler to SQLite | Engineering | ☐ |
| Three habits for consistent posting | Growth | ☑ |
| Why we self-host our tools | Opinion | ☑ |

## 3. Configure

| Field | Value for this tutorial |
| --- | --- |
| Enabled | ☑ |
| Persona | Indie Hacker / Builder in Public |
| AI provider | Server default |
| Cadence | `09:00, 18:00` |
| Plan ahead (days) | `7` |
| Recycle evergreen topics | ☑ |
| Target channels | your channel(s) |

Click **Save**.

## 4. Fill the calendar

Click **Fill slots now**, or just wait: while autopilot is enabled, the scheduler fills slots every 5 minutes. For each future slot within the horizon that doesn't already have an autopilot post, Open Post:

1. picks the eligible topic with the lowest "used" count. Eligible means never used, or evergreen with recycling on.
2. generates content with the selected provider (platform versions for X, LinkedIn, Reddit and Bluesky).
3. schedules it for that slot and increments the topic's count.

When no topic is eligible, it stops. In this example, the one non-evergreen topic is used once, and the two evergreen topics fill the remaining slots.

## 5. Review

Open **Queue** or **Calendar**. Autopilot posts carry an `autopilot` badge and a "generated by …" line. If a provider failed, the line shows the fallback reason. Edit or delete anything before it's due.

**Manual approval workflow:** leave **Enabled** unticked. Use **Fill slots now** or **Generate one now** when you want drafts, review them in the Queue, and delete what you don't like. Posts are only created when you click.

## 6. Generate from a specific topic

Each topic has a **Generate from this** button, which schedules one post 30 minutes from now. The API equivalent is `POST /api/autopilot/generate-now` with `{"topicId":"topic_…"}`. You can also pass `scheduledFor`.

## Personas

| Key | Tone |
| --- | --- |
| `thought_leader` | Authoritative and forward-looking. Strategic lessons, no hype |
| `indie_hacker` | Authentic and transparent. Shipping lessons and trade-offs |
| `technical_architect` | Engineering rigor, trade-offs and concrete patterns |
| `contrarian_analyst` | Challenges conventional wisdom with clear reasoning |
| `viral_storyteller` | Strong first-line hook, short narrative, crisp takeaway |

LLM providers receive the persona instructions. The heuristic engine uses fixed neutral templates, picked deterministically from the topic text.
