# Dashboard Guide

The dashboard is served at `/` by the same process as the API (`public/index.html`, `public/app.js`). It holds no data of its own: everything is read from and written to the REST API. It refreshes every 30 seconds, except while you're typing.

The header badge shows **`live` or `SANDBOX MODE`**, the storage engine (`node:sqlite`, `better-sqlite3` or `json`) and the server's default AI provider.

If the server has `API_TOKEN` set, the dashboard asks for the token once and keeps it in `sessionStorage` for that browser tab only.

## Overview

<img src="https://raw.githubusercontent.com/CodesbyFebin/Open-Post/main/assets/screenshots/overview.png" alt="Overview" width="100%">

- **Scheduled / Published / Failed + partial / Channels**: counts from `GET /api/analytics`.
- **Next up**: the next five scheduled posts.
- **Deliveries per day**: successful channel deliveries over the last 14 days. Sandbox deliveries count too.
- **Get started** checklist: shown until you have at least one channel and one post.

Open Post doesn't fetch likes, reach or other engagement from the networks, so none are shown.

## Compose

<img src="https://raw.githubusercontent.com/CodesbyFebin/Open-Post/main/assets/screenshots/compose.png" alt="Compose" width="100%">

| Control | What it does |
| --- | --- |
| Core content | Default text for every channel |
| Topic + persona + **Draft with AI** | Calls `POST /api/generate`, then fills the content and platform boxes. Shows which engine wrote it |
| X / LinkedIn / Reddit title / Reddit body / Bluesky | Optional per-platform text. Blank boxes use the core content |
| Counters | X 280 (per thread part, with the part count), LinkedIn 3000, Bluesky 300. They turn red over the limit |
| Channels | Tick the channels to publish to |
| Publish at | Local date and time in your browser, sent as UTC |
| Tags, Evergreen | Stored on the post |
| **Schedule** | Saves with status `scheduled` |
| **Save draft** | Saves with status `draft`. The scheduler ignores drafts |
| **Publish now** | Saves, then calls `publish-now`. Shows one toast per channel |
| **Clear** | Resets the form |
| Preview | Shows the text that each ticked channel type will receive |

When you edit a post from the Queue or Calendar, the title changes to **Edit post** and saving updates the existing post.

## Queue

<img src="https://raw.githubusercontent.com/CodesbyFebin/Open-Post/main/assets/screenshots/queue.png" alt="Queue" width="100%">

- Filter by status: `draft`, `scheduled`, `publishing`, `published`, `partial`, `failed`.
- Each card shows the status, the time, the channels, and badges for `autopilot` and `evergreen`. It also shows the attempt count, the "generated by" line, and the last six delivery log lines (links, `sandbox (not sent)`, or the error).
- **Edit**, **Publish now** (hidden once published) and **Delete**.

## Calendar

<img src="https://raw.githubusercontent.com/CodesbyFebin/Open-Post/main/assets/screenshots/calendar.png" alt="Calendar" width="100%">

- A month grid starting on Monday. Use ‹ › to change month. Today is outlined.
- Posts appear as chips, coloured by status. Click a chip to edit it.
- Click an empty part of a day to open Compose with the time set to 09:00 that day.

## Channels

<img src="https://raw.githubusercontent.com/CodesbyFebin/Open-Post/main/assets/screenshots/channels.png" alt="Channels" width="100%">

- Add a channel with a type, name, optional handle and optional env prefix, plus the subreddit (Reddit) or URL (webhook).
- Each card shows **● credentials found** or **● missing: VAR_A, VAR_B**, along with the prefix in use.
- **Disable / Enable** and **Remove**.

Credentials themselves are never entered here. See [Channels](Channels).

## Autopilot

<img src="https://raw.githubusercontent.com/CodesbyFebin/Open-Post/main/assets/screenshots/autopilot.png" alt="Autopilot" width="100%">

- Settings: enabled, persona, AI provider, cadence, days ahead, evergreen recycling, target channels. Use **Save**.
- **Generate one now**: saves the settings, then creates one post 30 minutes from now.
- **Fill slots now**: saves the settings, then fills every empty slot.
- Topic queue: add or remove topics. Each one shows its pillar, an evergreen badge and how many times it's been used, plus a **Generate from this** button.

See [Tutorial: Autopilot Setup](Tutorial-Autopilot-Setup).
